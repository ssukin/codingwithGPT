# Magic 8 Ball

A tiny browser app that shakes a Magic 8 Ball and picks one of the classic 20 answers.

This repository is for Coding with GPT on Mondays and Tuesdays at 2:45–4:10 pm.

## How to open it

Double-click `index.html` to open the app in your web browser. Click **Shake the ball** to get an answer.

There are no packages to install and no server to start.
